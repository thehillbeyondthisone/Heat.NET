## Notes

### Non-Destructive Approach
All original asset directories remain untouched. The `/site/images/` directory contains only essential assets for the cleaned version. During HTML cleanup, we can:
1. Update paths to point to `/site/images/` for organized assets
2. Copy additional assets as needed
3. Reference original directories for less critical images

### Wayback Machine Artifacts
Many images in asset directories are Wayback Machine UI elements (toolbar icons, archive.org branding). These can be excluded from the cleaned version.

### Trophy System Priority
Trophy images are critical for Phase 3 implementation. The Honor Trophies and Retired Trophies directories contain ~200+ trophy graphics that will need to be:
1. Cataloged and inventoried
2. Associated with trophy data
3. Organized by game/tournament
4. Integrated into database
