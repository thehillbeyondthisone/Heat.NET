# Original HEAT.NET Archive

This directory contains all the original files from the HEAT.NET Wayback Machine archive, preserved in their original state for reference and historical purposes.

## Directory Structure

```
original_archive/
├── html_pages/              # Original HTML pages from the archive
│   ├── index.html           # Main homepage
│   ├── index - Copy.html    # Backup copy
│   ├── HEAT.NET.html        # Main portal
│   ├── HEAT2.html           # Alternative homepage
│   ├── 10Six.htm            # 10Six game channel
│   ├── Footsoldiers.html    # Footsoldiers game page
│   ├── HEAT.NET __ STORE.html          # Store page
│   ├── HEAT.NET __ Diablo.html         # Diablo page
│   ├── HEAT __ Retired HEAT Trophies.html  # Trophy archive
│   ├── Heat Registration.mhtml         # Registration page
│   └── more/                # 1997 original archive
│
├── asset_directories/       # Original asset directories (*_files)
│   ├── 10Six_files/         # 10Six page assets (683 KB)
│   ├── HEAT2_files/         # HEAT2 page assets (206 KB)
│   ├── HEAT.NET_files/      # Main portal assets (773 KB)
│   ├── HEAT.NET __ STORE_files/        # Store assets (2.2 MB)
│   ├── Footsoldiers_files/  # Game page assets (699 KB)
│   ├── HEAT __ Honor Trophies_files/   # Trophy assets (2.6 MB)
│   └── HEAT __ Retired HEAT Trophies_files/  # Trophy archive (2.6 MB)
│
└── root_images/             # Original root-level images (25 files)
    ├── Logos and branding
    ├── Game screenshots
    ├── UI elements
    └── headline_heatstore.swf (Flash file)
```

## Purpose

These files are preserved as-is from the Internet Archive/Wayback Machine for:

1. **Historical Reference** - Original snapshots from 1997-2003
2. **Asset Source** - Original images, CSS, and JavaScript
3. **Comparison** - To compare with the cleaned version in `/site`
4. **Backup** - Complete backup of the archive before cleanup

## Contents

- **10 HTML pages** - Original pages with Wayback Machine artifacts
- **7 asset directories** - Images, CSS, and JavaScript (~13 MB)
- **25 root images** - Logos, screenshots, and graphics
- **1 Flash file** - Store headline animation (needs conversion)

## Wayback Machine Artifacts

These files contain Wayback Machine additions:
- Archive.org toolbar and branding
- Playback JavaScript (wombat.js, ruffle.js, etc.)
- Archive CSS and styling
- Timestamp comments and metadata

## Usage

To browse the original archive:
1. Serve from the project root with a static file server
2. Navigate to `original_archive/html_pages/index.html`
3. Note: Some links may be broken due to Wayback Machine URL rewriting
